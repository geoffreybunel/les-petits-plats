# Les Petits Plats

Les Petits Plats is a recipe search engine focused on implementing an optimized search algorithm in JavaScript.

The project explores different ways to filter large datasets efficiently.

## Features

- Dynamic recipe search
- Multiple filters (ingredients, appliances, utensils)
- Real-time filtering
- Optimized search algorithm

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## Getting Started

Clone the repository:

git clone https://github.com/geoffreybunel/les-petits-plats.git

Open the `index.html` file in your browser.
